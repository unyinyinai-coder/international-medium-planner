How to use Version 5

Start with My Profile to save your name, class and subject. These values prefill new plans.

Mark Sent records that you believe you sent the plan. It does not verify delivery or approval.

1. Each teacher opens this app on their own phone and fills a Daily or Weekly Plan.

2. Save Plan stores it on that phone only. Use Saved Plans to edit, print to PDF, export a single JSON file, or share a plan using Android Share. The leader imports that JSON in School Leader tab, reviews it and exports Review Decisions; teacher imports decisions in Backup tab.

3. When internet is available, use Share Plan and choose Email, WhatsApp or another installed app. Select the school leader as recipient yourself. This is file sharing, not automatic submission to a central dashboard.

4. Back up regularly. For migrating from Version 1, export a JSON backup in Version 1 and import it here. Opening a different HTML file may use a different storage location.

5. To test offline, turn off Wi-Fi/mobile data and reopen the extracted index.html from My Files. Offline data durability depends on the browser; never rely on it as the only copy.

Privacy: Do not send backups to unauthorized people. The School Leader tab supports local file review and an optional cloud fetch for authorized administrators. Cloud sync requires HTTPS hosting, a Supabase database and login configured separately. Offline file exchange remains available.
