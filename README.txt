International MEDIUM Weekly Teaching Planner V5

Open index.html for local-only use on Android or desktop. Cloud sync requires HTTPS hosting, a Supabase project, setup.sql, and accounts. Do not put secret/service_role keys in the app.

IMPORTANT: Local HTML opened via file:// or content:// cannot provide reliable PWA caching or cloud login. To use auto sync, host all files on HTTPS.

Offline plans are stored in browser localStorage. Export backups often. Imported legacy backups do not auto-upload until edited and saved while signed in. Use one device at a time per account during pilot.

See SETUP_GUIDE.txt and setup.sql.
